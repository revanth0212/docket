# Docket Documentation

Docket is an open-source, self-hosted **Second Brain as a Service**.
Unlike simple RAG systems, Docket models memory after human cognition:
memories have **sectors**, **validity over time**, **salience scores**, and
**adaptive decay**.

## What makes Docket different?

- **Cognitive Memory Model** — Not flat embeddings. Memories are classified
  into sectors: episodic, semantic, procedural, emotional, reflective.
- **Temporal Knowledge Graph** — Ask "what was true on March 1st?"
- **Composite Retrieval** — Vector + graph + salience + recency + temporal
- **Adaptive Decay** — Per-sector forgetting curves
- **RBAC Access Control** — Resource-based policies on every memory
