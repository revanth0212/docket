# User Guide

Welcome to the Docket User Guide. This section covers everything you need to
run, configure, and use Docket as your personal second brain.

## What you'll find here

- **[Quick Start](/docs/users/quickstart)** — Get Docket running in 5 minutes
- **[Configuration](/docs/users/configuration)** — YAML config, env vars, adapters
- **[Ingestion](/docs/users/ingestion)** — Upload files, async jobs, supported types
- **[Querying](/docs/users/querying)** — Natural language search, temporal queries
- **[Memory Modes](/docs/users/memory-modes)** — Flat vs rich cognitive memory
- **[Hosting](/docs/users/hosting)** — Standalone, Docker, serverless

## Who this is for

You are a **user** if you want to:
- Run Docket locally or on a server
- Ingest photos, documents, and notes
- Query your knowledge with natural language
- Configure adapters via YAML without writing code

If you want to build plugins or adapters instead, see the
[Developer Guide](/docs/developers).
