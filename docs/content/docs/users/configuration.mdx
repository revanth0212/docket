# Configuration

Docket is configured through `config/defaults.yaml` (shipped) and
`config/config.yaml` (your overrides, gitignored).

## Priority

1. `defaults.yaml` — built-in defaults
2. `config.yaml` — user overrides
3. `CORTEX_*` environment variables
4. CLI arguments (future)

## Environment variables

Any config value can be overridden via `CORTEX_{PATH}`:

```bash
CORTEX_ADAPTERS_LLM_DEFAULT=openai
CORTEX_SERVER_PORT=8080
CORTEX_MEMORY_MODE=rich
```

You can also use interpolation in YAML:

```yaml
adapters:
  llm:
    providers:
      kimi:
        config:
          apiKey: "${CORTEX_KIMI_API_KEY:-}"
```

## Key sections

### Server

```yaml
server:
  port: 3000
  host: "127.0.0.1"
```

### Logging

```yaml
logging:
  level: "info"   # debug | info | warn | error
  format: "pretty" # pretty | json
```

### Memory mode

```yaml
memory:
  mode: "flat"  # flat | rich
```

See [Memory Modes](/docs/users/memory-modes) for the full rich-mode config.

### Adapters

Each adapter category has a `default` and a map of `providers`:

```yaml
adapters:
  llm:
    default: "ollama"
    providers:
      ollama:
        adapter: "@docket/llm-ollama"
        config:
          baseUrl: "http://localhost:11434"
          model: "llama3.2"
```

Supported categories: `llm`, `embedder`, `store`, `blob`, `queue`.
