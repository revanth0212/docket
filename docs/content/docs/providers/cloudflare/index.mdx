# Cloudflare Provider

Cloudflare offers a generous free tier and global edge deployment. All services run close to your users with minimal latency.

## What You Get

| Adapter | Implementation | Cloudflare Service |
|---------|---------------|-------------------|
| LLM | Cloudflare Workers AI | `@cf/meta/llama-3.1-8b-instruct` |
| Embedder | Cloudflare Workers AI | `@cf/baai/bge-base-en-v1.5` |
| Store | Cloudflare D1 | SQLite-compatible edge database |
| Blob | Cloudflare R2 | S3-compatible object storage |
| Queue | Cloudflare Queues | Distributed message queue |

## Architecture

```
User → Cloudflare Edge → Workers AI (LLM/Embedder)
                      → D1 (Store)
                      → R2 (Blob)
                      → Queues (Background jobs)
```

## Free Tier Limits

| Service | Limit |
|---------|-------|
| Workers AI | 10,000 neurons/day |
| D1 | 5M rows read/day, 100K rows write/day |
| R2 | 10M Class A ops/month, 1M Class B ops/month |
| Queues | 1M operations/month |

## Serverless deployment

Deploy Docket to Cloudflare Workers using the handler at
`src/platform/serverless/cloudflare-workers/handler.js`. It runs on the
Cloudflare edge and pairs with D1, R2, Workers AI, and Queues. See
[Hosting](/docs/users/hosting#cloudflare-workers) for deployment
instructions.
